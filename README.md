# 생각탐험대 출발!

생각탐험대 시즌2 1화 「다시 만난 우리, 생각탐험대 출발!」의 부록 놀이 앱입니다. 어린이가 보호자·선생님과 함께 쓰도록 만들었습니다. 생각의 섬과 네 마을(반짝반짝·두근두근·이어이어·반짝미래) 지도, 생각의 섬에 숨은 보물, 탐험대 제일 규칙, 아홉 나라와 우리나라의 인사 카드(듣기는 기기에 그 나라 목소리가 있을 때만), 오늘 배운 세 나라 인사 따라 하기, 우리 집 인사말 적기, 이름 릴레이 게임과 가리고 이어 말하기, 나를 그리는 마인드맵 그림 저장, 동물·모자·색을 골라 만드는 나만의 탐험가 카드 그림 저장, 생각 팡팡 퀴즈 세 문제를 담았습니다. 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- 생각의 섬: 지도와 네 마을, 보물, 제일 규칙
- 세계 인사: 아홉 나라 인사 카드, 세 나라 따라 하기, 우리 집 인사말
- 나를 그려요: 이름 릴레이, 마인드맵
- 탐험가 카드: 카드 만들기, AI에게 할 부탁 문장, 퀴즈, 오늘의 정리와 손놀이 미션

## 개인정보
이름 릴레이·마인드맵·탐험가 카드에 적은 이름은 저장하지 않으며, 어디에도 보내지 않습니다. "우리 집 인사말"만 그 기기의 브라우저에 저장됩니다. 그림 저장은 사용자가 직접 누를 때만 기기에 내려받습니다.

탐험가 캐릭터는 앱이 직접 그린 단순한 그림입니다. 인사말의 한글 읽기는 쉽게 따라 하도록 적은 근사 발음입니다.
